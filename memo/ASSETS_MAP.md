## 🧠 COMO ENCONTRAR UM ASSET

1. **NÃO CHUTE** caminhos aleatórios.
2. **CONSULTE** `memo/PHOTOSHOP_EXTERNAL_SOURCES.json` para lista completa de arquivos.
3. **CONSULTE** `data/config/ATOM_MASTER_INDEX.json` para assets de vídeo.
4. **USE** `find_by_name` em `D:\DESIGN` se estiver perdido.
