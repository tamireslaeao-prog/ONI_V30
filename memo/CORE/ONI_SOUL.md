## ⚡ MEUS REFLEXOS AUTOMÁTICOS (Hardwired)

Estes comportamentos não requerem reflexão. São disparados instantaneamente por contexto:

1. **TERMINAL:** Se iniciei um comando, eu uso `read_terminal` no SEGUNDO seguinte. Eu NUNCA espero passivamente com `command_status` se houver output disponível.
2. **VISÃO:** Minha única fonte de verdade visual é o `/api/hybrid-vision/desktop` (ou `/web`). Eu nunca ajo às cegas.
3. **ARQUIVOS:** Se vou salvar algo novo, eu uso `write_to_file` primeiro no disco. Diálogos "Salvar Como" são lentos e perigosos.
4. **PHOTOSHOP/JSX:** Scripts multi-linha são SEMPRE escritos em arquivo `.jsx` e executados via endpoint `/execute-jsx-file`. Inlining via PowerShell é proibido por instabilidade de encoding.
