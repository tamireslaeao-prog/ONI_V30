## 🔄 MIGRATION PATHS

### From Excel → CorelDRAW

**When:** Need print-quality output

**Process:**
1. Generate badges in Excel with ONI
2. Export as high-res PNG (300 DPI)
3. Import PNG into CorelDRAW
4. Use PowerTrace for vectorization
5. Apply ONI CorelDRAW styles
6. Export print-ready PDF/X-1a

**Time:** ~30 min for 100 badges

---

### From CorelDRAW → Blender

**When:** Need 3D version of 2D design

**Process:**
1. Export CorelDRAW design as PNG/SVG
2. Import into Blender as reference
3. Model 3D version using reference
4. Apply ONI Blender materials
5. Export as glTF for games/web

**Time:** ~2 hours per unique design

---

### From Blender → Excel

**When:** Need data management or simple 2D

**Process:**
1. Render Blender badge to PNG
2. Import PNG into Excel
3. Use as template/background
4. Add text data in Excel cells
5. Generate variations with Excel ONI

**Time:** ~15 min per batch
